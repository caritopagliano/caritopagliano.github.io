01Problem

Our document system doesn't connect to the tracker, so every application's details (name, ID number, procedure) had to be typed in by hand. When a delivery of up to 200 documents arrived, that meant hours of repetitive typing, and with it typos and tracking errors.

02What I built

It reads the report (PDF or pasted text), finds the date, and produces a clean 7-column row for every case, ready to paste into the Excel tracker.

It cross-checks the fees paid to work out which documents will actually arrive. For example, an "ID + passport" case with no passport fee means an emergency passport was issued on the spot, so only the ID card is expected. Cases that need a human decision are flagged for review instead of guessed.

Key decision

Nothing goes into the tracker unchecked → errors and items like pending IDs are flagged for review first.

03Result

Daily intake in seconds

Each day's applications go into the tracker in a few seconds of paste and check. When the delivery arrives, there's nothing left to type.
