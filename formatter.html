Case study 03 of 05

Data Formatter

A tool that reads the day's cash report and turns every case into a clean row, ready to paste into the tracker.

Key result
3–4 hours → seconds
When it's used
End of each day

01Problem

Documents were only added to the tracker when they arrived. The document system doesn't connect to the tracker, so everything was typed by hand. When a diplomatic pouch arrived with 150–200 documents, staff spent hours on repetitive data entry, which caused typos and tracking errors.

02What I built

A tool that reads the day's cash report (PDF or pasted text), detects the date, and turns every case into a clean 7-column row ready to paste into the Excel tracker.

It cross-checks the fees paid to work out which documents will actually arrive. For example, an "ID + passport" case with no passport fee means an emergency passport was issued on the spot, so only the ID card is expected. Cases that need a human decision are flagged for review instead of guessed.

04Result

3–4 hours → seconds

3–4+ hours of manual entry per batch of 150–200 documents became a few seconds of upload, check and paste. Every application is tracked from the day it's started, with far fewer typing errors.
