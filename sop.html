Case study 05 of 05

Standard Operating Procedure (SOP)

One page that runs the whole document workflow.

Problem
Process knowledge lived in people's heads, with no single view of where each document was.
Built
A one-page SOP that follows each document's journey and names the tool for every step.
Result
4 stages, end to end
Key decision
One page that shows which tool to use at each step.

The process

  1. 1

    Daily Intake

    Load the daily payments report into the Formatter, confirm any flagged cases, and paste the result into Case Tracking.

  2. 2

    Desk Review

    Add the final ID number when a temporary one is replaced, and add the applicant's email for arrival notices. Formula columns are never edited by hand.

  3. 3

    Delivery Arrives

    Record the delivery date and reference, then scan each document. Documents found in the tracker are marked "At the desk". Unknown documents are flagged for separate handling.

  4. 4

    Document Collection

    The applicant signs a paper slip at the counter. Staff keep the barcode stub and scan all stubs in one batch at closing, and the case is archived automatically.

  • Design ruleNo computer at the counter: slips are scanned in one batch at closing, so service stays fast.
  • Design ruleFormula columns are locked.
  • Design ruleUnknown documents are flagged, not mixed in.

01Problem

Process knowledge lived in people's heads, so onboarding and handovers were slow, and there was no single view of which documents never arrived, which were received and which hadn't been collected.

02What I built

It ties all the tools together and gives full visibility of:

  • Documents that never arrived
  • Documents received
  • Documents not yet collected
Key decision

One page that follows the document's journey and shows which tool to use at each step → anyone new can run the process from day one.

03Result

4 stages, end to end

My colleague learned the full process from the SOP and runs it step by step. Because everything is written down, cover and handovers no longer depend on one person.
