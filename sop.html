01Problem

Process knowledge lived in people's heads, so onboarding and handovers were slow, and there was no single view of which documents never arrived, which were received and which hadn't been collected.

02What I built

It ties all the tools together and gives full visibility of:

  • Documents that never arrived
  • Documents received
  • Documents not yet collected
Key decision

One page that follows the document's journey and shows which tool to use at each step → anyone new can run the process from day one.

03Result

4 stages, end to end

My colleague learned the full process from the SOP and runs it step by step. Because everything is written down, cover and handovers no longer depend on one person.
